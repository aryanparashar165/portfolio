# Aryan Parashar — Personal Portfolio

My first personal portfolio website, created to showcase my early journey in web development, programming, education, certifications, and professional experience.

This project represents an earlier stage of my development journey, when I was primarily exploring frontend development, web technologies, and building my first personal presence on the web.

## 🌐 About the Portfolio

The website includes sections for:

- 👋 Introduction and personal profile
- 👨‍💻 Web development services
- 🎓 Education
- 💼 Professional experience
- 📜 Certifications
- 📩 Contact information
- 🔗 Social and professional profiles
- 📄 Resume

The original portfolio also included a certification gallery with links to external credential-verification pages. :contentReference[oaicite:0]{index=0}
